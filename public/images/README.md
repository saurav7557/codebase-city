# Portfolio Personal Imagery Guidelines

This directory stores real portfolio photography and project interface captures.

## Asset Structure

1. **Profile Photograph**:
   - Path: `public/images/profile.jpg`
   - Specifications: Square (1:1), Recommended resolution: 800x800px.
   - Displayed in: Recruiter Mode profile panel, Developer HQ dossier.

2. **Project Interface Screenshots**:
   - Path: `public/images/projects/<project-slug>.png`
   - Specifications: 16:9 or 16:10 aspect ratio, Recommended resolution: 1920x1080px or 1280x720px.
   - Standard Slugs:
     - `meshpay-tower.png` — Distributed Payment & Settlement Architecture
     - `groweasy-ai-lab.png` — SMB AI Platform & Recommendation Engine
     - `ai-ip-protection.png` — Computer Vision & Perceptual Hashing Pipeline
     - `blockchain-verification-hub.png` — On-Chain Verification & Provenance System
     - `open-source-hub.png` — Developer Tooling & Package Registry
     - `achievement-center.png` — Scaled Deployment & Architecture Retrospectives

When an image file is added to these paths, the UI automatically renders the verified image with an architectural caption strip. If an image is absent, a neutral architectural blueprint schematic is displayed with zero layout shift or broken link icons.
